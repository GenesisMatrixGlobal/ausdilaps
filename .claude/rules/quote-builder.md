Stores geometry ONLY — never a derived area, which would become a second source of truth that disagrees with `measureShape()` the moment the maths improves — plus the frame, so reopening flies back to it. Ids are regenerated on open; a bad field drops its own shape and is counted, not the whole file. There is no automatic persistence, deliberately: these are scratch measurements, and a silently-restored set from last week is a worse default than an empty map.
  - Needs **`NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY`** — a SECOND, separate key from `GOOGLE_MAPS_API_KEY`. Never merge them: the server one carries Geocoding, Directions and Static Maps quota, and Maps JS puts its key in the client bundle by design. Without it the Measure tab shows a "not configured" message and every other tab is unaffected.

- ⚠️ **`lib/maps/building-markup-file.ts` persisted a lot's colour ONLY when it was red** (`...(n.color === "red" ? … : {})`), so every non-red lot reopened blue. Fixed 2026-09-16. Harmless while lots could only be red or blue; it would have erased the meaning of every closeout markup.
